- UK :: Сполучник вводить результат, який суперечить очікуванню з попереднього речення. ~ところが~ сильніше підкреслює несподіваний поворот, ніж нейтральне ~しかし~. Звичайно пишеться каною; ~ところで~ означає «до речі».
- LEVEL :: beginner
- REGISTER :: neutral
