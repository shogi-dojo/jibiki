** Learner notes
*** note-s-1584090-001-001
:PROPERTIES:
:END:
- UK :: Перехідне дієслово ґодан на -く (порівняйте з дієсловом だく / daku):
- Розрізнення:
  - だく (daku) частіше вживається у розмовній мові про фізичні обійми або тримання дитини на руках.
  - いだく (idaku) має поетично-піднесений відтінок у фізичному значенні (значення 1), і є основним виразом для плекання почуттів, мрій, надій та сумнівів (значення 2):
    - 夢 / 希望を抱く (плекати мрію / надію)
    - 疑問 / 不安を抱く (мати сумніви / тривогу)
    - 悪意を抱く (мати злі наміри).
- LEVEL :: beginner
- REGISTER :: neutral
