** Learner notes
*** note-s-1530970-001-001
:PROPERTIES:
:END:
- UK :: Слово 無理 (むり) функціонує як na-прикметник та іменник із загальним значенням неможливості або відсутності раціональної підстави. У щоденній японській мові воно має три ключові вжитки: 1) стан неможливості (無理です / muri desu — «це неможливо / непосильно»); 2) дія понад силу, перевтома (無理をする / muri o suru — «перепрацьовувати, рвати жили», часто у ввічливому проханні піклуватися про себе: 無理をしないでください); 3) прислівник примусу (無理に / muri ni — «силоміць, насильно, через силу»).
- LEVEL :: beginner
- REGISTER :: neutral
** Examples
*** ex-1530970-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: 無理をしないで、疲れたら少し休んでください。
- READING :: むりをしないで、つかれたらすこしやすんでください。
- ROMAJI :: Muri o shinaide, tsukaretara sukoshi yasunde kudasai.
- UK :: Не перевтомлюйтеся; якщо втомилися, будь ласка, трохи відпочиньте.
- EN :: Don't overdo it; please rest a little if you get tired.
- FOCUS :: 無理をしないで
*** ex-1530970-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: 一日でこの分厚い本を全部読むのは無理です。
- READING :: いちにちでこのぶあついほんをぜんぶよむのはむりです。
- ROMAJI :: Ichinichi de kono buatsui hon o zenbu yomu no wa muri desu.
- UK :: Прочитати всю цю товсту книгу за один день неможливо.
- EN :: It is impossible to read this whole thick book in one day.
- FOCUS :: 無理です
*** ex-1530970-001-003
:PROPERTIES:
:LEVEL: intermediate
:REGISTER: neutral
:END:
- JA :: 嫌がる子供に無理に野菜を食べさせても、好き嫌いは治りません。
- READING :: いやがるこどもにむりにやさいをたべさせても、すききらいはなおりません。
- ROMAJI :: Iyagaru kodomo ni muri ni yasai o tabesasete mo, sukikirai wa naorimasen.
- UK :: Навіть якщо змушувати дитину їсти овочі силоміць, перебірливість у їжі не зникне.
- EN :: Even if you force a reluctant child to eat vegetables, it won't fix their picky eating.
- FOCUS :: 無理に
