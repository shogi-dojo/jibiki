** Learner notes
*** note-s-1000730-001-001
:PROPERTIES:
:END:
- UK :: Загальновживаний вираз оцінки та заборони (зазвичай пишеться хіраґаною いけない):
- Основні граматичні конструкції:
  1. Оцінка: いけないこと (погана / неприпустима справа).
  2. Заборона: 〜てはいけない (не можна робити: 触ってはいけない — не можна торкатися).
  3. Обов'язок: 〜なければいけない (мусити / зобов'язаний зробити).
  4. Вигук прикрого спохвату: いけない！ (Ой лишенько! Отакої!).
  5. Непереносимість алкоголю: お酒はいけない (не п'ю алкоголю).
- LEVEL :: beginner
- REGISTER :: neutral

:LEVEL: beginner
:REGISTER: neutral

- ROMAJI :: Rouka o hashitte wa ikemasen.
- UK :: У коридорі бігати не можна.
- EN :: You must not run in the hallway.

- READING :: ともだちとのやくそくのじかんにおくれそうになってあわてていえをでたのに、とちゅうでさいふをわすれたことにきづいて「いけない！」とこえがでました。
- ROMAJI :: Tomodachi to no yakusoku no jikan ni okuresou ni natte awatete ie o deta noni, tochuu de saifu o wasureta koto ni kidzuite "ikenai!" to koe ga demashita.
- UK :: Я поспіхом вибіг із дому, бо запізнювався на зустріч, але дорогою згадав про забутий гаманець і вигукнув: «Ой лишенько!».

- READING :: どれほどいそがしいじょうきょうであっても、じぶんのりえきのためにたにんにめいわくをかけたりるーるをやぶったりすることはにんげんとしてけっしてゆるされないいけないこういです。
- ROMAJI :: Dorehodo isogashii joukyou de atte mo, jibun no rieki no tame ni tanin ni meiwaku o kaketari rule o yabuttari suru koto wa ningen to shite kesshite yurusarenai ikenai koui desu.
- UK :: Хоч би як ви поспішали, завдавати іншим незручностей чи порушувати правила заради власної вигоди — це неприпустимий і непристойний учинок.
- EN :: However busy the circumstances, inconveniencing others or breaking rules for personal benefit is an unforgivable and wrong act as a human being.
- FOCUS :: いけない行為です
