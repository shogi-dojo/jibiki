# Система японсько-української транслітерації

> **For agents and contributors (English summary).** Transliterate Japanese into Ukrainian by
> actual Japanese pronunciation: **ші**, **чі**, **джі**, **ґ**, **дз**, **шьо**, never the
> Polivanov system (сі, ті, дзі, г, з, сьо). Examples: **шьоґі** (not сьоґі), **ґо** (not го),
> **суші** (not сусі), **Фуджі** (not Фудзі), **Хірошіма** (not Хіросіма). This file is the
> complete, public policy; every Ukrainian gloss, note and example in this repository follows it.
>
> **Enforcement.** The rules are executable. The [`yanagi`](https://github.com/shogi-dojo/yanagi)
> gem owns the kana→romaji and kana→Cyrillic engines used here (`scripts/validate_entry.rb`,
> `lib/exporters/houhou_vocab_matcher.rb`), checks Ukrainian text for Polivanov spellings, and
> verifies its rules data against this document:
>
> ```bash
> yanagi cyrillic しゅうさい                      # => шюсай
> yanagi doc-sync docs/transliteration-rules.md
> yanagi verify-gold
> ```
>
> The same checker runs on the web at https://jibiki.japan-dojo.com/yanagi.

Ця інструкція визначає правила практичної транскрипції та транслітерації японських власних назв, термінів і лексичних одиниць українською мовою: для словника Jibiki, художніх перекладів, наукових праць і глосаріїв. Це правила руху НЯШ (Нова Японська Школа, https://jibiki.japan-dojo.com/njs).

## 1. Базова таблиця відповідностей (фонетична система)

Використовуємо **українську фонетичну транслітерацію з японської**, наближену до реального японського звучання (а НЕ російську систему Поліванова чи англізований ромадзі без адаптації):

| Японська мора / склад | Кирилізація | Заборонено (Поліванов / англіцизми) | Приклади |
|---|---|---|---|
| し (shi) | **ші** | сі | Шіншю, шімей, Шінобу |
| ち (chi) | **чі** | ті | Чіба, чікара, Чійо |
| つ (tsu) | **цу** | тсу | Цукі, Цуґару, кацу |
| ふ (fu) | **фу** | ху | Фуджі, Фукуока, фусекі |
| じ (ji) / ぢ (dji) | **джі** | дзі, зі | Осараґі Джіро, Нікка джіхен, мейджін |
| ざ / ず / づ / ぜ / ぞ | **дз** (дза, дзу, дзе, дзо) | з (за, зу, зе, зо) | Нодзава, Одзакі, сейдза, кандзуме, кайдзое |
| が / ぎ / ぐ / げ / ご | **ґ** (ґа, ґі, ґу, ґе, ґо) | г | Ґо Сейґен, Отаке, шьоґун, шьоґі |

## 2. Палаталізовані склади (йоон / 拗音)

1. **М'які голосні (я, ю)**: Палаталізовані склади передаємо відповідними йотованими голосними після пом'якшеного приголосного:
   - しゃ (sha) → **шя** (шяку, кішя)
   - しゅ (shu) → **шю** (Шюсай, Шюхо, Шюей, Шіншю)
   - ちゃ (cha) → **чя** (чядо, чяван)
   - ちゅ (chu) → **чю** (чюдан, чюґок)
   - じゃ (ja) → **джя** (джянтен, маджян)
   - じゅ (ju) → **джю** (ренджю, джюні)
   - りゃ / りゅ / りょ → **ря / рю / рьо** (Рю, Рьокан)
   - きゃ / きゅ / きょ → **кя / кю / кьо** (Кьото, кюдан)
   - にゃ / にゅ / にょ → **ня / ню / ньо** (Ньорай)
   - ひゃ / ひゅ / ひょ → **хя / хю / хьо** (Хьоґо)
   - みゃ / みゅ / みょ → **мя / мю / мьо** (Мьоджін)

2. **Склади з «о» після шиплячих та африкат**: Перед «о» після шиплячих і африкат використовуємо **м'який знак** (ьо):
   - しょ (sho) → **шьо** (шьоґун, шьоґі, Шіншьо, шьодан)
   - ちょ (cho) → **чьо** (Чьоґю, чьоджін)
   - じょ (jo) → **джьо** (джьосекі, джьодан)

3. **Розмежування зі звичайними морами**: Це правило стосується виключно палаталізованих складів (йоон). Звичайні мори передаємо без додаткового пом'якшення чи йотації: `кадзоедоші`, `кайдзое`.

## 3. Специфічні та комбінаторні правила

### 3.1. い після голосної: завжди «і», ніколи «ї»
Голосну **い (i) після будь-якої іншої голосної** у складі японського кореня або основи передаємо літерою **«і»**, а **НЕ «ї»**:
- В японській мові в цій позиції немає йотації [j] — це окрема вокалічна мора.
- Приклади: **Каруідзава** (軽井沢), **Ґоі** (五井), **Кіін** (棋院), **нуімон** (縫い紋), **Отеай** (大手合).
- *Примітка:* Це правило стосується внутрішньояпонської транслітерації. Українські граматичні відмінкові закінчення з «ї» функціонують за загальними правилами українського правопису (наприклад: *у «Нараї»*, *у Кансаї*, *Нономія* → *Нономії*).

### 3.2. Складовий носовий ん (n)
- Перед губними приголосними **«п»** та **«б»** передаємо як **«м»**: *момпуку*, *Самбо*.
- Перед **«м»** та всіма іншими приголосними залишаємо **«н»**: *санмайкьо*, *ранма*, *Шіншю*.

### 3.3. Довгі голосні
- Довгі голосні в художньому перекладі та загальному вжитку **не подвоюємо**: *Отаке*, *Ошіма*, *Офуна*, *Кьото*, *Шюсай*.
- У наукових текстах за потреби фіксації довготи може застосовуватися латинський макрон або двокрапка у транскрипційних вставках (наприклад: *kan'yōku* або *кан'йо:ку*).

### 3.4. Африката じ = джі (НЕ дзі)
- じ та ぢ передаються як **джі**: *Осараґі Джіро* (не «Дзіро»), *мейджін* (не «мейдзін»).

### 3.5. Сокуон っ
- Значок **っ** подвоює наступний приголосний **перед проривними «п» і «к»**: *Іппекі*, *кеппекі*, *ґоджюппо*, *Ніккай*, *Хоккекьо*, *Ґаккай*, *Джяккоджі*, *Дзеккен*.
- Перед шиплячими та африкатами подвоєння **не передаємо**, бо сполуки шш, чч і ддж чужі українській мові: *шічяку* (не «шіччяку»), *Тешю* (не «Тешшю»), *доджін-дзаші* (не «дзашші»).
