- UK :: Дієслово (五段), що передає внутрішнє відчуття нетерпіння або квапливості (напр., 気が急く — душі не терпиться, 心を急く). Відоме також із прислів'я 急いては事を仕損じる («поспішиш — справу зіпсуєш»).
- LEVEL :: advanced
- REGISTER :: neutral

:LEVEL: neutral
:REGISTER: neutral

- FOCUS :: 急いて
