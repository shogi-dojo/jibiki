- UK :: Іменник та сур-дієслово (=確認する=, перевіряти, підтверджувати), що означає перевірку фактів, документів чи стану справ для переконання в точності або безпеці: =本人確認= (підтвердження особи), =安全を確認する= (переконатися в безпеці), =予約を確認する= (підтвердити бронювання).
- LEVEL :: intermediate
- REGISTER :: neutral
