** Learner notes
*** note-s-1308300-001-001
:PROPERTIES:
:END:
- UK :: Іменник «ринок / базар (місце торгівлі)»:
- Вживання:
  - Конкретний ринок із лавками: 朝市 (あさいち / asaichi — ранковий ринок), 青空市場 (あおぞらいちば / aozora ichiba — вуличний базар просто неба).
  - Типові сполучення: 市場に行く (いちばにいく / ichiba ni iku — йти на ринок), 市場の魚 (いちばのさかな / ichiba no sakana — риба з ринку).
- Відмінність від синонімів:
  - 市場 (いちば / ichiba) — фізичне місце, де торгують; 市場 (しじょう / shijou) — «ринок» в економічному сенсі (株式市場 / かぶしきしじょう / kabushiki shijou — фондовий ринок); スーパー (suupaa) — супермаркет.
- Ключові колокації:
  - 市場が開く (いちばがひらく / ichiba ga hiraku — ринок відкривається)
  - 市場の人込み (いちばのひとごみ / ichiba no hitogomi — юрба на ринку)
- LEVEL :: beginner
- REGISTER :: neutral
