- UK :: Брати із собою людей або тварин (для неживих предметів уживається 持つ / 持って行く): 連れて行く (брати із собою / вести когось туди), 連れて来る (приводити із собою сюди), 犬を連れて散歩する (гуляти з собакою). Граматична конструкція 〜につれて означає «разом із тим, як... / у міру того, як...».
- LEVEL :: beginner
- REGISTER :: neutral
