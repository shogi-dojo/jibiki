- UK :: =今さら遅い= — тепер уже запізно, =今さら聞けない= — тепер ніяково чи пізно запитувати. Відчуття, що сприятливий момент минув; =今= саме тепер без цього відтінку. Не обов'язково календарно пізній вечір.
- LEVEL :: intermediate
- REGISTER :: neutral
