- UK :: Анатомічний термін «шлунок»:
- Поширені сполучення:
  - 胃が痛い (боли́ть шлунок)
  - 胃もたれ (важкість у шлунку після їжі)
  - 胃薬 (いぐすり / igusuri — ліки для шлунка)
  - 胃カメラ (いかめら / ikamera — гастроскопія).
- Відмінність від お腹 (onaka): お腹 позначає живіт загалом, тоді як 胃 — саме шлунок як орган.
- LEVEL :: beginner
- REGISTER :: neutral
