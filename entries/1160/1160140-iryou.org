** Learner notes
*** note-s-1160140-001-001
:PROPERTIES:
:END:
- UK :: Іменник «медицина, медичне обслуговування»:
- Типові сполучення:
  - 医療を受ける (いりょうをうける / iryou o ukeru — отримувати медичну допомогу).
  - 医療費 (いりょうひ / iryouhi — витрати на лікування).
  - 医療機関 (いりょうきかん / iryou kikan — медичні заклади).
  - 先進医療 (せんしんいりょう / senshin iryou — передові методи лікування).
- Відмінність від близьких слів:
  - 医療 (いりょう / iryou) — медицина як система й сфера лікування.
  - 治療 (ちりょう / chiryou) — лікування конкретної хвороби чи пацієнта.
  - 医学 (いがく / igaku) — медична наука.
- LEVEL :: beginner
- REGISTER :: neutral
