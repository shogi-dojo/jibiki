- UK :: Іменник, утворений із 串 («шпажка, рожен») та 刺す («протикати, настромлювати») з одзвінченням на ざし. Позначає нанизування м'яса, риби чи овочів на паличку або шампур для смаження (наприклад, 串刺しにする — «настромити на шпажку»).
- LEVEL :: advanced
- REGISTER :: neutral
