- UK :: Звільнення з клітки, неволі, пут чи ув'язнення (~籠から放れる~ — вирватися з клітки, ~手から放れる~ — вислизнути з рук). Не плутати з омофоном ~離れる~ (віддалятися, відходити). Парне перехідне дієслово: ~放す~ (відпускати).
- LEVEL :: intermediate
- REGISTER :: neutral
