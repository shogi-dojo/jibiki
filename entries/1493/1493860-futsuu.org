- UK :: Припинення або блокування транспортного сполучення (поїздів, автошляхів через снігопад, зсув ґрунту) чи зв'язку (телефонних ліній). Часті сполучення: `不通になる` (перериватися, припинятися), `音信不通` (відсутність звісток/зв'язку від когось). Не плутати з омофоном `普通` (звичайний).

- REGISTER :: neutral
