** Learner notes
*** note-s-1337370-001-001
:PROPERTIES:
:END:
- UK :: Іменник від дієслова 祝う (いわう / iwau — вітати, святкувати):
- Типові сполучення:
  - お祝いを言う (おいわいをいう / o-iwai o iu — сказати слова вітання).
  - 誕生祝い (たんじょういわい / tanjou iwai — привітання з днем народження).
  - 祝いの席 (いわいのせき / iwai no seki — урочистий стіл, банкет).
- Відмінність від близьких слів:
  - 祝い (いわい / iwai) — сама подія вітання або святкування.
  - お祝い (おいわい / o-iwai) — ввічливіша форма; також означає подарунок.
  - おめでとう (おめでとう / omedetou) — саме слово вітання: «вітаю!».
- LEVEL :: beginner
- REGISTER :: neutral
