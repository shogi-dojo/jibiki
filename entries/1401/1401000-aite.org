** Learner notes
*** note-s-1401000-001-001
:PROPERTIES:
:END:
- UK :: Багатозначне слово «той, з ким мають справу»:
  1. Партнер у грі, розмові чи житті: 話し相手 (hanashiaite — співрозмовник), 遊び相手 (товариш для ігор), 結婚相手 (партнер для шлюбу).
  2. Інша сторона / співрозмовник (значення 2): 相手の気持ち (почуття співрозмовника / іншої сторони).
  3. Суперник / опонент (значення 3): 対戦相手 (суперник у матчі).
- Вирази: 相手にする (зважати на когось / мати справу), 相手にならない (не рівня / слабкий для суперництва).
- LEVEL :: beginner
- REGISTER :: neutral
