*** note-s-1002000-001-001
:PROPERTIES:
:END:
- UK :: Шанобливе позначення дитини співрозмовника (префікс お- + 子 + -さん): お子さん (ваша дитина / їхня дитина). Для власної дитини вживають скромніші 子ども (kodomo) або うちの子 (uchi no ko), ніколи не お子さん.
- LEVEL :: beginner
- REGISTER :: formal
