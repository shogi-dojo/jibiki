** Learner notes
*** note-s-1481350-001-001
:PROPERTIES:
:END:
- UK :: Іменник «дошка / планка / пластина»:
- Основні контексти:
  1. Дерев'яна дошка: 木の板 (дерев'яна дошка), 一枚板 (いちまいいだ / ichimaiita — суцільна масивна дошка).
  2. Лист металу або скла: 鉄板 (теппан / залізний лист), 看板 (かんばん — вивіска).
  3. Дошка для нарізання: まな板 (まないた / manaita).
  4. Шеф-кухар: 板さん (ita-san, скорочення від 板前 — суші-кухар).
  5. Сцена: 板につく (органічно вжитися в роль, бути на своєму місці).
- LEVEL :: beginner
- REGISTER :: neutral
