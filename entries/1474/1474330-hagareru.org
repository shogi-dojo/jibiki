- UK :: 剥がれる — неперехідне дієслово про відокремлення покриття або приклеєного предмета: シールが剥がれる, 塗装が剥がれる. Перехідне 剥がす означає відклеїти чи зняти щось. Не тотожне просто впасти 落ちる: передбачається попереднє з'єднання з поверхнею.
- LEVEL :: intermediate
- REGISTER :: neutral
