** Learner notes
*** note-s-1774100-001-001
:PROPERTIES:
:END:
- UK :: Буквально — піднята вгору або занесена для кроку нога (з 揚げる «підіймати» + 足 «нога»). Найчастіше це слово вживається у сталому фразеологізмі 揚げ足を取る («чіплятися до слів, ловити на обмовках» — за аналогією з підсічкою піднятої ноги суперника).
- LEVEL :: advanced
- REGISTER :: neutral

:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral

- READING :: とうろんのばでは、あいてのあげあしをとるよりもけんせつてきないけんをのべるべきだ。
- UK :: Під час дискусії замість того, щоб чіплятися до слів опонента, варто висловлювати конструктивні аргументи.
- FOCUS :: 揚げ足
