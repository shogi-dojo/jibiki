- UK :: Іменник архітектурної та побутової лексики (明かり «світло» + 取り «вловлювання, забирання»). Позначає невелике вікно на даху, у стіні під стелею або над дверима, призначене насамперед для пропускання денного світла в темне приміщення.
- LEVEL :: advanced
- REGISTER :: neutral
