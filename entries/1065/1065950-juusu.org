** Learner notes
*** note-s-1065950-001-001
:PROPERTIES:
:END:
- UK :: Запозичення з англійської (~juice~). Означає фруктовий або овочевий сік. Часто вживається з назвами фруктів: オレンジジュース (апельсиновий сік), リンゴジュース (яблучний сік), トマトジュース (томатний сік). Згідно з японськими стандартами маркування, назву «ジュース» на упаковці дозволено вказувати лише для 100% натурального соку.
- LEVEL :: beginner
- REGISTER :: neutral

- READING :: つめたいジュースをのみました。

- FOCUS :: ジュース

:PROPERTIES:
:LEVEL: neutral

- UK :: Мій щоденний звичай — пити на сніданок апельсиновий сік зі свіжих фруктів.
- EN :: It is my daily routine to drink orange juice made from fresh fruit for breakfast.
- FOCUS :: ジュース

- UK :: За японським законодавством лише напої зі 100% вмістом фруктового соку можуть позначатися словом «сік».
- EN :: Under Japanese law, only beverages containing 100 percent fruit juice can be labeled as juice.
- FOCUS :: ジュース
