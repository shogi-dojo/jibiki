** Learner notes
*** note-s-1345605-001-001
:PROPERTIES:
:END:
- UK :: Прислівник そろそろ (sorosoro) найчастіше вказує на те, що настав слушний момент для якоїсь дії: そろそろ帰りましょう (пора вже повертатися), そろそろ始めましょう (почнімо вже). Також може позначати повільний, обережний рух («потихеньку», «помалу»).
- LEVEL :: beginner
- REGISTER :: neutral
** Examples
*** ex-1345605-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: もう十時ですから、そろそろ寝る時間です。
- READING :: もうじゅうじですから、そろそろねるじかんです。
- ROMAJI :: Mou juuji desu kara, sorosoro neru jikan desu.
- UK :: Уже десята година, тож пора вже лягати спати.
- EN :: It is already ten o'clock, so it is about time to go to bed.
- FOCUS :: そろそろ寝る
*** ex-1345605-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: 外が暗くなってきたので、そろそろ失礼いたします。
- READING :: そとがくらくなってきたので、そろそろしつれいいたします。
- ROMAJI :: Soto ga kuraku natte kita node, sorosoro shitsurei itashimasu.
- UK :: Надворі вже стемніло, тому мені вже час відкланюватися.
- EN :: It has gotten dark outside, so I should be taking my leave now.
- FOCUS :: そろそろ失礼
*** ex-1345605-001-003
:PROPERTIES:
:LEVEL: intermediate
:REGISTER: neutral
:END:
- JA :: 気温も上がってきたので、そろそろ公園の桜が咲き始める季節ですね。
- READING :: きおんもあがってきたので、そろそろこうえんのさくらがさきはじめるきせつですね。
- ROMAJI :: Kion mo agatte kita node, sorosoro kouen no sakura ga sakihajimeru kisetsu desu ne.
- UK :: Потеплішало, тож незабаром настане пора, коли в парку зацвіте сакура.
- EN :: The temperature has risen, so it will soon be the season when cherry blossoms begin to bloom in the park.
- FOCUS :: そろそろ公園の
