** Learner notes
*** note-s-1224880-001-001
:PROPERTIES:
:END:
- UK :: Ввічливий (шанобливий) еквівалент прикметника いい / よい (ii / yoi). Дуже типовий для ввічливого та ділового мовлення (кейґо):
1. Запит про дозвіл або згоду: 〜てもよろしいでしょうか (Чи можу я...?, Чи не заперечуєте ви...?).
2. Згода або підтвердження: よろしいです (Гаразд, домовлено).
3. Зручність для співрозмовника: ご都合はよろしいですか (Чи зручно вам?).
- LEVEL :: beginner
- REGISTER :: formal
** Examples
*** ex-1224880-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: formal
:END:

- READING :: おなまえをうかがってもよろしいですか。
