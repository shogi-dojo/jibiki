- UK :: 被告を起訴する — висунути обвинувачення для судового розгляду. У новинах 起訴 не означає, що винуватість уже встановлено вироком; затримання, обвинувачення й засудження — різні етапи, які контекст має розрізняти.
- LEVEL :: intermediate
- REGISTER :: neutral
