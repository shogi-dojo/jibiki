** Learner notes
*** note-s-1215260-001-001
:PROPERTIES:
:END:
- UK :: Дієслово 間に合う (まにあう) є неперехідним дієсловом і означає «встигати кудись / робити щось вчасно». Подія, транспорт чи дедлайн позначається часткою に (наприклад, 電車に間に合う — встигнути на поїзд, 会議に間に合う — встигнути на зустріч). У значенні 2 вираз 間に合っています (まにあっています) використовується як ввічлива відмова: «дякую, мені цього достатньо / більше не потрібно».
- LEVEL :: beginner
- REGISTER :: neutral
** Examples
*** ex-1215260-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: 走れば、まだ七時の電車に間に合います。
- READING :: はしれば、まだななじのでんしゃにまにあいます。
- ROMAJI :: Hashireba, mada nanaji no densha ni maniaimasu.
- UK :: Якщо побігти, ми ще встигнемо на семигодинний поїзд.
- EN :: If we run, we can still make the seven o'clock train.
- FOCUS :: 間に合います
*** ex-1215260-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:

- READING :: しめきりにまにあうように、いっしょうけんめいれぽーとをかきました。
- ROMAJI :: Shimekiri ni maniau you ni, isshoukenmei repooto o kakimashita.
- UK :: Я старанно писав звіт, щоб встигнути до кінцевого терміну.
- EN :: I wrote the report diligently so as to make the deadline.
- FOCUS :: 間に合う

- ROMAJI :: Juutai ni makikomaremashita ga, nantoka kaigi no kaishi jikan ni maniaimashita.
- UK :: Хоча ми й потрапили в затор, нам якось удалося встигнути до початку наради.
- EN :: Although we got caught in a traffic jam, we somehow managed to make it in time for the start of the meeting.
