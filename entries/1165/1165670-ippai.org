- UK :: Слово 一杯 (いっぱい / ippai) має кілька значень: 1) «одна чашка / склянка»: コーヒー一杯 (чашка кави); 2) «випити чарку»: 一杯飲む (випити по чарці); 3) повний / ситий (часто хіраґаною): お腹がいっぱい (я наївся), 人でいっぱい (повно людей); 4) прислівник максимуму: 精一杯 (з усіх сил), 今月いっぱい (до кінця місяця); 5) лічильник для кальмарів, крабів (іка іппай) та човнів.

- REGISTER :: neutral
