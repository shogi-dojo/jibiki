** Learner notes
*** note-s-1279680-001-001
:PROPERTIES:
:END:
- UK :: Найчастіше вживається у заперечній формі 構わない (не має значення / не біда / все гаразд): 構いません (без проблем / дозволено), お構いなく (не турбуйтеся про мене / не звертайте уваги), 構わず (незважаючи на). У стверджувальній формі також означає приділяти увагу (構ってほしい — хотіти уваги) або втручатися (значення 3–4).
- LEVEL :: beginner
- REGISTER :: neutral
** Examples
*** ex-1279680-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:

- READING :: わたしのことはかまわないでください。
- ROMAJI :: Watashi no koto wa kamawanaide kudasai.
- UK :: Будь ласка, не переймайтеся через мене.
- EN :: Please don't worry about me.
- FOCUS :: 構わないで

- READING :: かれはまわりのひとのめをすこしもかまわず、じぶんのすきなことだけにじょうねつをそそいでいます。

- UK :: Він анітрохи не зважає на погляди інших і присвячує себе винятково тому, що йому подобається.
