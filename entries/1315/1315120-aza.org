- UK :: Традиційна дрібна адміністративно-територіальна одиниця в Японії (частина села або містечка):
- 大字 (おおあざ / ooaza — великий куток)
- 小字 (こあざ / koaza — малий куток)
- 字 (あざ / aza — дільниця / куток села).
Не плутати з найпоширенішим читанням кандзі 字 (じ / ji — ієрогліф, знак, літера, почерк) чи омофоном 痣 (あざ / aza — родимка, синець).

- REGISTER :: formal
