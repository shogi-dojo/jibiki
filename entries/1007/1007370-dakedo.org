*** note-s-1007370-001-001
:PROPERTIES:
:END:
- UK :: Розмовний протиставний сполучник на початку речення (скорочення від ~だけれども~). Широко вживається в повсякденній розмовній мові серед друзів та знайомих. Більш офіційний еквівалент — ~しかし~.
- LEVEL :: beginner
- REGISTER :: informal
** Examples
*** ex-1007370-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: 行きたいです。だけど今日はお金がありません。
- READING :: いきたいです。だけどきょうはおかねがありません。
- UK :: Я хочу піти. Але сьогодні в мене немає грошей.
- EN :: I want to go. But I don't have money today.
- FOCUS :: だけど

:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: 薬を飲みました。だけどまだ熱が下がりません。
- READING :: くすりをのみました。だけどまだねつがさがりません。
- UK :: Я прийняв ліки. Але температура все ще не спадає.
- EN :: I took medicine. However, the fever still hasn't gone down.
- FOCUS :: だけど

- FOCUS :: だけど
