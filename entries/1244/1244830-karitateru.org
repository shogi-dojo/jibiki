- UK :: Мисливське 駆り立てる означає вигнати звіра з укриття або виполохати його. JMdict також відзначає написання 狩り立てる для цього сенсу. Об'єктом є тварина; це окреме значення, яке не слід змішувати з переносним психологічним спонуканням до вчинку.
- LEVEL :: intermediate
- REGISTER :: neutral
