- UK :: Книжний іменник, що також уживається як означення з часткою の (憂国の). Поєднує канджі 憂 (журба, тривога) та 国 (країна, держава), передаючи глибоку стурбованість майбутнім своєї країни. Характерні сталі словосполучення: 憂国の情 (почуття патріотичної тривоги за країну) та 憂国の士 (патріот, відданий син вітчизни).
- LEVEL :: advanced
- REGISTER :: neutral
