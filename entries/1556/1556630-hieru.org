** Learner notes
Означає «ставати холодним» або «охолоджуватися». Використовується для опису того, як температура чогось (наприклад, погоди, напою або тіла) знижується. Це неперехідне дієслово (дія відбувається сама по собі). Перехідний аналог — 冷やす (hiyasu).
** Examples
*** Beginner
- JA :: コーヒーが冷えました。
- READING :: コーヒー が ひえました。
- UK :: Кава охолола.
- EN :: The coffee got cold.
- FOCUS :: 冷えました
*** Neutral
- JA :: 夜は少し冷えるので、ジャケットを持って行きます。
- READING :: よる は すこし ひえる ので、ジャケット を もって いきます。
- UK :: Вночі стає трохи прохолодно, тому я візьму з собою куртку.
- EN :: It gets a little chilly at night, so I'll take a jacket.
- FOCUS :: 冷える
*** Intermediate
- JA :: 昨晩はとても冷えたので、風邪を引いてしまった。
- READING :: さくばん は とても ひえた ので、かぜ を ひいて しまった。
- UK :: Минулої ночі сильно похолодало, тому я застудився.
- EN :: It got very cold last night, so I caught a cold.
- FOCUS :: 冷えた
