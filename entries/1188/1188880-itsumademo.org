** Learner notes
*** note-s-1188880-001-001
:PROPERTIES:
:END:
- UK :: Прислівник «назавжди / скільки завгодно довго»:
- Значення й вживання:
  - «Назавжди, довіку» — про стан, що триватиме без кінця: いつまでも待っています (いつまでもまっています / itsumademo matte imasu — чекатиму, скільки буде потрібно).
  - Побажання довголіття: いつまでもお元気で (いつまでもおげんきで / itsumademo o-genki de — будьте завжди здорові та бадьорі).
  - З відтінком нетерпіння чи докору — «занадто довго, досить уже»: いつまでも泣かないで (いつまでもなかないで / itsumademo nakanaide — не плач вічно, досить уже).
- Порівняння з близькими словами:
  - 永遠に (えいえんに / eien ni — повіки, вічно) — книжніше, філософсько-літературне; いつまでも — нейтральне, розмовне.
  - ずっと (ずっと / zutto — весь час, безперервно) — про тривалість у минулому й теперішньому; いつまでも — про нескінченне майбутнє.
- Пишеться переважно хіраганною формою いつまでも (позначка uk у словнику).
- LEVEL :: beginner
- REGISTER :: neutral
