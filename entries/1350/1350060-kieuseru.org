** Learner notes
*** note-s-1350060-001-001
:PROPERTIES:
:END:
- UK :: Неперехідне дієслово (いちだん). Підсилений та виразніший синонім дієслова 消える, що підкреслює повне й остаточне зникнення предмета з поля зору або розвіювання сумнівів, страху чи болю (跡形もなく消え失せる — зникнути без сліду).
- LEVEL :: advanced
- REGISTER :: neutral
** Examples
*** ex-1350060-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: 不安が消え失せる。
- READING :: ふあんがきえうせる。
- UK :: Тривога безслідно розвіюється.
- FOCUS :: 消え失せる
*** ex-1350060-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: 温かい太陽が昇ると谷間を覆っていた深い霧はあっという間に消え失せる。
- READING :: あたたかいたいようがのぼるとたにまをおおっていたふかいきりはあっというまにきえうせる。
- UK :: Коли сходить тепле сонце, густий туман, що вкривав долину, миттєво розвіюється.
- FOCUS :: 消え失せる
*** ex-1350060-001-003
:PROPERTIES:
:LEVEL: intermediate
:REGISTER: neutral
:END:
- JA :: 本番が始まる前までは激しい緊張で胸が締めつけられていたが、舞台の上で最初の音を鳴らした瞬間にすべての迷いが消え失せるのを感じた。
- READING :: ほんばんがはじまるまえまでははげしいきんちょうでむねがしめつけられていたが、ぶたいのうえでさいしょのおとをならしたしゅんかんにすべてのまよいがきえうせるのをかんじた。
- UK :: До початку виступу груди стискало від сильного хвилювання, але тієї миті, коли на сцені пролунав перший звук, я відчув, як усі вагання безслідно щезають.
- FOCUS :: 消え失せる
