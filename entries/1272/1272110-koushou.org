*** note-s-1272110-001-001
:PROPERTIES:
:END:
- UK :: 交渉する — обговорювати умови чи розбіжності для досягнення домовленості: 条件を交渉する・相手と交渉する. と називає іншу сторону; слово описує процес і не означає, що угода неодмінно вже укладена.
- LEVEL :: intermediate
- REGISTER :: neutral

:REGISTER: neutral

- FOCUS :: 交渉

- EN :: Before entering negotiations, we clarified which conditions could change and which had to be maintained.
- FOCUS :: 交渉
