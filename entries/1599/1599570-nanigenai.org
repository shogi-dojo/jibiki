- UK :: =何気ない一言= — слова, сказані без особливого наміру, =何気なく= — ненароком або невимушено. Не обов'язково байдужість до людини; видима буденність може приховувати сильний вплив. Пишеться також =なにげない=.
- LEVEL :: intermediate
- REGISTER :: neutral
