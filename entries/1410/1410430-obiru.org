- UK :: 帯びる буквально описує носіння меча, відзнаки або предмета при собі: 刀を帯びる. Має книжний відтінок і не є звичайним дієсловом для будь-якого одягу; 着る та 身につける ширше вживаються в побуті. Об'єкт із を називає те, що носять.

- REGISTER :: neutral
