** Learner notes
Використовується, коли хтось починає якусь дію або процес. Це перехідне дієслово, тому воно часто вимагає додатка з часткою を (wo).
** Examples
- JA :: 新しい仕事を始める。
- READING :: あたらしいしごとをはじめる。
- UK :: Я починаю нову роботу.
- EN :: I am starting a new job.
- FOCUS :: beginner
- JA :: 彼は自分の会社を始めました。
- READING :: かれはじぶんのかいしゃをはじめました。
- UK :: Він заснував власну компанію.
- EN :: He started his own company.
- FOCUS :: neutral
- JA :: 雨が降り始めたので、急いで帰りましょう。
- READING :: あめがふりはじめたので、いそいでかえりましょう。
- UK :: Почав іти дощ, тому давайте поспішимо додому.
- EN :: It has started to rain, so let's hurry home.
