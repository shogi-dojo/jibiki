- UK :: Утворюється приєднанням суфікса -め («досить, злегка, з ухилом у бік») до основи прикметника 固い; вживається як な- або の-прикметник та іменник. Дуже поширене в кулінарії для замовлення текстури страви — наприклад, 麺は固め («локшина аль денте / твердіша») або 固めに茹でる («зварити не розварюючи»).
- LEVEL :: advanced
- REGISTER :: neutral
