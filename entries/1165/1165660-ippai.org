- UK :: Спортивний термін на позначення однієї поразки (антонім: 一勝 / いっしょう — одна перемога):
- 三勝一敗 (さんしょういっぱい — три перемоги, одна поразка)
- 一敗地に塗れる (いっぱいちにまみれる — зазнати нищівного розгрому).
Не плутати з омофонами:
- 一杯 (いっぱい / ippai — повно, вщерть; один келих/чашка).
- LEVEL :: intermediate
- REGISTER :: neutral
