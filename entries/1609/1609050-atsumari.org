** Learner notes
*** note-s-1609050-001-001
:PROPERTIES:
:END:
- UK :: Віддієслівний іменник від 集まる (atsumaru — збиратися разом):
- Означає неформальну або організовану зустріч групи людей:
  - 家族の集まり (kazoku no atsumari — родинна зустріч / коло сім'ї)
  - 友達の集まり (посиденьки з друзями)
  - 集まりが良い / 悪い (добре / погано збираються; висока або низька явка).
- Для суто офіційних ділових засідань частіше вживається 会議 (kaigi).
- LEVEL :: beginner
- REGISTER :: neutral
