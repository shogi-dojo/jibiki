- UK :: Предикативний прикметник (на -な) та прислівник, характерний насамперед для кансайського діалекту (関西弁). У сучасному письмі зазвичай записується каною (ぎょうさん). Сполучається як із іменниками (ぎょうさんな人 — «безліч людей»), так і з дієсловами без частки (ぎょうさん食べる — «наїстися досхочу, їсти багато»).
- LEVEL :: advanced
- REGISTER :: neutral
