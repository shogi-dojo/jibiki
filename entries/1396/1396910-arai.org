- UK :: І-прикметник на позначення грубої текстури або структури:
- 粗い (arai):
  - 目の粗い網 (сітка з великими вічками)
  - 粗い砂 (крупнозернистий пісок)
  - 作りが粗い (груба, неакуратна робота).
- Порівняйте з омофоном 荒い (arai — буйний, несамовитий: 波が荒い — бурхливі хвилі, 気性が荒い — запальний характер).
- Антонім: 細かい (komakai — дрібний, тонкий).
- LEVEL :: beginner
- REGISTER :: neutral
