** Learner notes
*** note-s-2007830-001-001
:PROPERTIES:
:END:
- UK :: Перехідне складене дієслово (також пишеться 食い縛る; майже завжди у вислові 歯を食いしばる або 奥歯を食いしばる). Позначає сильне зціплення зубів, щоб витерпіти біль, приборкати сльози чи докласти граничних зусиль.
- LEVEL :: advanced
- REGISTER :: neutral
** Examples
*** ex-2007830-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: 歯を食いしばる。
- READING :: はをくいしばる。
- UK :: Стиснути зуби (терплячи труднощі чи біль).
- FOCUS :: 食いしばる
*** ex-2007830-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: 悔し涙がこぼれないように奥歯を強く食いしばるしかなかった。
- READING :: くやしなみだがこぼれないようにおくばをつよくくいしばるしかなかった。
- UK :: Щоб не покотилися сльози образи, залишалося тільки міцно зціпити кутні зуби.
- FOCUS :: 食いしばる
*** ex-2007830-001-003
:PROPERTIES:
:LEVEL: intermediate
:REGISTER: neutral
:END:
- JA :: 激しい足の痛みに襲われながらも、マラソン選手は歯を食いしばる思いで最後の坂道をゴールに向かって走り抜いた。
- READING :: はげしいあしのいたみにおそわれながらも、マラソンせんしゅははをくいしばるおもいでさいごのさかみちをゴールにむかってはしりぬいた。
- UK :: Попри гострий біль у ногах, марафонець, зціпивши зуби, пробіг останній підйом до самого фінішу.
- FOCUS :: 食いしばる
