** Learner notes
*** note-s-1199720-001-001
:PROPERTIES:
:END:
- UK :: Іменник та сур-дієслово (=回復する=, відновлювати/відновлюватися), що означає повернення до попереднього доброго чи нормального стану (здоров'я, сил, погоди, економіки, довіри): =天気の回復= (поліпшення погоди), =景気回復= (економічне відновлення), =疲労回復= (зняття втоми/відновлення сил), =信頼を回復する= (відновити довіру).
- LEVEL :: intermediate
- REGISTER :: neutral
** Examples
*** ex-1199720-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: 天気が回復しました。
- READING :: てんきがかいふくしました。
- UK :: Погода покращилася.
- EN :: The weather has improved.
- FOCUS :: 回復しました
*** ex-1199720-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: 十分に睡眠をとって、体力を回復させましょう。
- READING :: じゅうぶんにすいみんをとって、たいりょくをかいふくさせましょう。
- UK :: Нумо добре виспимося та відновимо сили.
- EN :: Let's get enough sleep and recover our physical strength.
- FOCUS :: 回復させましょう
*** ex-1199720-001-003
:PROPERTIES:
:LEVEL: intermediate
:REGISTER: neutral
:END:
- JA :: 景気が本格的に回復するには、まだしばらく時間がかかりそうだ。
- READING :: けいきがほんかくてきにかいふくするには、まだしばらくじかんがかかりそうだ。
- UK :: Схоже, знадобиться ще деякий час, перш ніж економіка повноцінно відновиться.
- EN :: It seems it will take some time before the economy recovers in earnest.
- FOCUS :: 回復するには
