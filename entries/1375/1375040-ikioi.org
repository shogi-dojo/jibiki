- UK :: Іменник та прислівник (勢いよく / 勢いで):
- Означає силу, динаміку, напір або піднесення:
  - 勢いよく (бурхливо, щосили, хвацько)
  - 勢いがつく (набирати обертів / розгону)

  - その場の勢いで (під впливом моменту / за інерцією).
- LEVEL :: beginner
- REGISTER :: neutral
