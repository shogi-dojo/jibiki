** Learner notes
*** note-s-1593070-001-001
:PROPERTIES:
:END:
- UK :: Перехід через фізичну перешкоду, кордон чи межу, або подолання труднощів чи часу (~山を越える~ — переходити через гори, ~国境を越える~ — перетинати кордон, ~峠を越える~ — минути найважчий момент / подолати кризу, ~年を越える~ — зустрічати новий рік / зимувати). Зазвичай пишеться ієрогліфом ~越~ для простору й труднощів, тоді як перевищення норм чи кількостей позначається ~超~ (~超える~).
- LEVEL :: intermediate
- REGISTER :: neutral
