- UK :: Як іменник 繰り返し називає повторення дії чи фрагмента: 同じことの繰り返し, 繰り返しの練習. Може стосуватися практики, циклів або музичного рефрену. Не обов'язково негативне: повторення може бути потрібним для навчання, хоча контекст може виражати монотонність.
- LEVEL :: intermediate
- REGISTER :: neutral

- UK :: Навіть у вправі, яка здається простим повторенням, можна помітити відмінності, якщо щоразу зосереджуватися на одному завданні.
- EN :: Even practice that seems mere repetition can reveal differences if you focus on one task each time.
