- UK :: Іменник. Первісно слово 楊枝 позначало гілочку верби (яку жували для чищення зубів), а компонент 爪- вказує на маленький предмет розміром із ніготь; у побуті зубочистки зазвичай лічать лічильним суфіксом 本 (ほん).
- LEVEL :: advanced
- REGISTER :: neutral
