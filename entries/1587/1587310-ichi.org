** Learner notes
*** note-s-1587310-001-001
:PROPERTIES:
:END:
- UK :: Іменник (також дієслово suru) «положення / розташування / позиція»:
- Граматика:
  - Як іменник: 位置がいい (いちがいい / ichi ga ii — зручно розташований), 位置を決める (いちをきめる / ichi o kimeru — визначити місце).
  - Як дієслово 位置する (いちする / ichi suru — бути розташованим, перебувати): 山の中腹に位置する (やまのちゅうふくにいちする / yama no chuufuku ni ichi suru — розташований на середині схилу гори).
- Відмінність від синонімів:
  - 場所 (ばしょ / basho) — просто «місце» як ділянка простору; 位置 — положення чогось відносно інших об'єктів.
  - 所在地 (しょざいち / shozaichi) — офіційна адреса розташування установи.
- Ключові колокації:
  - 位置につく (いちにつく / ichi ni tsuku — стати на позицію, зайняти своє місце)
  - 位置が悪い (いちがわるい / ichi ga warui — незручне розташування)
- LEVEL :: beginner
- REGISTER :: neutral
