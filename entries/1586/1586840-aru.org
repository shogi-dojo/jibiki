** Learner notes
*** note-s-1586840-001-001
:PROPERTIES:
:END:
- UK :: Преномінативне означення (連体詞 / rentaishi), зазвичай пишеться хіраґаною ある:
- Вказує на конкретний, але неназваний або невизначений об'єкт / людину / час:
  - ある日 (aru hi — одного дня, якось)
  - ある人 (aru hito — один чоловік / хтось)
  - ある場所 (якесь місце)
  - ある意味で (aru imi de — у певному розумінні / сенсі).
- Не плутайте з дієсловом 有る / ある (існувати, бути).
- LEVEL :: beginner
- REGISTER :: neutral
