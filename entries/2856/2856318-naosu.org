** Learner notes
*** note-s-2856318-001-001
:PROPERTIES:
:END:
- UK :: Перехідне дієслово 1-ї дієвідміни (五段):
- Канджі 治す пишеться виключно при зціленні від хвороб, травм або звичок:
  - 風邪を治す (лікувати застуду)
  - 病気を治す (вилікувати хворобу)
  - 癖を治す (позбутися звички).
- Неперехідне парне дієслово — 治る (なおる / naoru — одужувати, загоюватися).
- Для ремонту речей та виправлення помилок вживається омофон 直す (なおす / naosu).
- LEVEL :: beginner
- REGISTER :: neutral
