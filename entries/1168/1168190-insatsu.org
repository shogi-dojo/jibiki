- UK :: Іменник та перехідне дієслово suru (印刷する — друкувати, роздруковувати):
- Складається з 印 (відбиток) + 刷 (друкувати, наносити фарбу):
  - 印刷機 (いんさつき / insatsuki — друкарська машина, принтер)
  - 印刷会社 / 印刷所 (друкарня, поліграфічне підприємство)
  - 印刷部数 (いんさつぶすう / insatsu busuu — тираж видання).
- LEVEL :: beginner
- REGISTER :: neutral
