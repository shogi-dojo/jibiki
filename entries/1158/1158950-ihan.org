** Learner notes
*** note-s-1158950-001-001
:PROPERTIES:
:END:
- UK :: Іменник і дієслово suru «порушення / порушувати»:
- Граматика:
  - 違反 (いはん / ihan) — іменник; із する утворює неперехідне дієслово 違反する (いはんする / ihan suru — порушувати).
  - Типова конструкція: «правило/закон + に違反する» (на порушення вказує частка に): 交通規則に違反する (こうつうきそくにいはんする / koutsuu kisoku ni ihan suru — порушувати правила дорожнього руху).
- Типові сполучення:
  - スピード違反 (すぴーどいはん / supiido ihan — перевищення швидкості)
  - 駐車違反 (ちゅうしゃいはん / chuusha ihan — порушення правил паркування)
  - 契約違反 (けいやくいはん / keiyaku ihan — порушення договору)
- Відмінність від близьких слів:
  - 違反 (いはん / ihan) — порушення закону чи правила.
  - 違い (ちがい / chigai — різниця) — той самий корінь, але значення інше.
  - 犯す (おかす / okasu — вчиняти, порушувати) — дієслово про вчинення злочину чи помилки.
- LEVEL :: beginner
- REGISTER :: neutral
