** Learner notes
*** note-s-1533560-001-001
:PROPERTIES:
:END:
- UK :: І-прикметник. Складається з 面倒 (клопіт, турбота) та суфікса くさい (який підсилює ознаку небажаності чи неприємності). У розмовній мові найчастіше записується як めんどくさい або めんどい. Описує дію, процедуру або справу, яка вимагає багато зусиль чи часу, і за яку зовсім не хочеться братися через лінощі або набридливість (марудний, такий, що ліньки робити).
- LEVEL :: beginner
- REGISTER :: colloquial

:PROPERTIES:
:LEVEL: beginner
:REGISTER: colloquial
:END:

- READING :: そうじをするのはめんどうくさいけれど、へやをきれいにした。
- UK :: Прибирати мені ліньки, але я все ж навів лад у кімнаті.
- EN :: Cleaning up is a hassle, but I made my room neat.
- FOCUS :: 面倒くさい

- READING :: てつづきがめんどうくさくて、ついついしんせいをあとまわしにしてしまう。
- UK :: Оформлення документів настільки марудне, що я мимоволі відкладаю подання заяви на потім.
- EN :: The procedure is such a bother that I end up putting off the application.
- FOCUS :: 面倒くさくて

- READING :: ぱすわーどのていきてきなへんこうはめんどうくさいとかんじるが、せきゅりてぃをたもつためにはかかせない。
- UK :: Регулярна зміна паролів здається клопіткою справою, проте це необхідно для збереження безпеки.
- EN :: Changing passwords periodically feels bothersome, but it is indispensable for maintaining security.
- FOCUS :: 面倒くさい
