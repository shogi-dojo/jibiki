- UK :: Офіційно-книжне перехідне дієслово (односкладова основа 宣 + する), що вживається для урочистого оголошення початку, завершення, вироку чи рішення. Типові словосполучення: 開会を宣する («оголосити відкриття») та 無罪を宣する («винести виправдальний вирок»).
- LEVEL :: advanced
- REGISTER :: neutral
