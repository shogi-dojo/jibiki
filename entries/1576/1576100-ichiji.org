** Learner notes
*** note-s-1576100-001-001
:PROPERTIES:
:END:
- UK :: Часовий іменник «перша година / о першій»:
- Відлік часу:
  - 一時 (いちじ / ichiji) — «перша година»; про час після обіду кажуть 午後一時 (ごごいちじ / gogo ichiji — перша година дня), а про ніч — 午前一時 (ごぜんいちじ / gozen ichiji — перша година ночі).
  - Пів на першу — 一時半 (いちじはん / ichiji han).
- Не плутати читання того самого запису:
  - 一時 (いちじ / ichiji) — година; ідіома 一時 (ひととき / hitotoki) — коротка мить, «якийсь час».
- LEVEL :: beginner
- REGISTER :: neutral
