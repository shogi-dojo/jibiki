*** note-s-1382440-001-001

- UK :: Іменник, що означає «камінь» або «камінець». Використовується як для природного каміння (道にある石 - камінь на дорозі), так і для матеріалу (石の建物 - кам'яна будівля). Для позначення дорогоцінного каміння частіше використовується слово 宝石 (ほうせき).
- LEVEL :: beginner
- REGISTER :: neutral
