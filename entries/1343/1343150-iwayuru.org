- UK :: Займенниковий преномінальний прикметник (рентайсі / 連体詞):
- Зазвичай записується хіраґаною いわゆる:
  - Вживається безпосередньо перед іменником, посилаючись на загальноприйняту чи розмовну назву:
    - いわゆる「天才」 (так званий «геній»)
    - いわゆるエリート (так звана «еліта»)
    - いわゆる勝ち組 (так звані «переможці»).
  - Походить від архаїчної пасивної форми дієслова 言う (казати) + ゆ + る.
- LEVEL :: beginner
- REGISTER :: neutral
