- UK :: Загальновживаний вигук подяки (зазвичай пишеться хіраґаною ありがとう):
- Етимологічно походить від 有り難い (arigatai — «рідкісний, неоціненний»).
- Форми ввічливості:
  - ありがとう (arigatou — дружнє «дякую»).
  - ありがとうございます (arigatou gozaimasu — нейтрально-ввічливе «дякую»).
  - ありがとうございました (arigatou gozaimashita — ввічливе минуле «дякую за зроблене»).
  - どうもありがとうございます (підкреслено ґречне «щиро дякую»).
- LEVEL :: beginner
- REGISTER :: neutral
