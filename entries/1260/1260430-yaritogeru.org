- UK :: やり遂げる підкреслює, що розпочату справу завершили попри труднощі: 最後までやり遂げる, 仕事をやり遂げる. Близьке до 成し遂げる, але природне й для особистого чи повсякденного завдання, не лише великого досягнення. Просто やる не повідомляє, чи робота була повністю завершена.
- LEVEL :: intermediate
- REGISTER :: neutral
