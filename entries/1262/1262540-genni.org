- UK :: Книжний прислівник (від предикативного іменника 厳), що виражає вимогу беззастережного дотримання правил, заборон або обережності. Найчастіше поєднується з дієсловами 戒める («суворо застерігати»), 慎む («суворо утримуватися»), 禁止する («категорично забороняти»). Не плутати за звучанням із 現に («насправді, реально»).
- LEVEL :: advanced
- REGISTER :: neutral
