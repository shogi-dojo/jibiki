- UK :: Книжний прислівник (від 毫 — найтонша волосинка, дрібниця + частка も), що завжди вживається в заперечних реченнях для категоричного заперечення. Найчастіше трапляється у стійких висловах 毫も疑わない («ні краплі не сумніватися») та 毫も変わらない («анітрохи не змінюватися»).
- LEVEL :: advanced
- REGISTER :: neutral
