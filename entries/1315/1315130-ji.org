*** note-s-1315130-001-001
:PROPERTIES:
:END:
- UK :: Іменник 字 (じ / ji) позначає письмовий знак, літеру або ієрогліф. Входить до складу багатьох важливих слів: 漢字 (kanji — ієрогліфи), 数字 (suuji — цифри), 文字 (moji / monji — літери, символи). Вираз 字を書く (ji o kaku) означає «писати літери/ієрогліфи».
- LEVEL :: beginner
- REGISTER :: neutral
** Examples
*** ex-1315130-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: ノートに鉛筆で大きい字を書きました。
- READING :: ノートにえんぴつでおおきいじをかきました。
- ROMAJI :: Nooto ni enpitsu de ookii ji o kakimashita.
- UK :: Я написав олівцем у зошиті великі літери.
- EN :: I wrote big letters in the notebook with a pencil.
- FOCUS :: 大きい字を
*** ex-1315130-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: 彼の書く字はとても読みやすくて綺麗です。
- READING :: かれのかくじはとてもよみやすくてきれいです。
- ROMAJI :: Kare no kaku ji wa totemo yomiyasukute kirei desu.
- UK :: Літери, які він пише, дуже розбірливі й красиві.
- EN :: The characters he writes are very easy to read and beautiful.
- FOCUS :: 書く字は
*** ex-1315130-001-003

:REGISTER: neutral
:END:

- READING :: こくばんのじがちいさすぎて、きょうしつのうしろのせきからはよくみえませんでした。
- ROMAJI :: Kokuban no ji ga chiisasugite, kyoushitsu no ushiro no seki kara wa yoku miemasen deshita.
- UK :: Літери на дошці були занадто дрібними, тому з задніх рядів класу їх було погано видно.

- FOCUS :: 黒板の字が
