- UK :: Іменник, що зазвичай є скороченням від 真田紐 («шнур Санада» — міцна пласка стрічка з бавовняних чи шовкових ниток) або 真田編み (спосіб плаского виплітання, зокрема із соломи). Традиційно такі вироби використовують для перев'язування дерев'яних скриньок із посудом для чайної церемонії, оформлення обладунків та виготовлення поясів.
- LEVEL :: advanced
- REGISTER :: neutral
