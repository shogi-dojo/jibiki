- UK :: Іменник, утворений поєднанням числівника 一 (один) та 山 (гора); трапляється також у змішаному написанні ひと山. Позначає окрему гору або гірську ділянку в просторових описах, наприклад 一山向こう (за однією горою, по той бік гори).
- LEVEL :: advanced
- REGISTER :: neutral
