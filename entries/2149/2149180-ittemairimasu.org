- UK :: Скромно-шанобливий варіант (кенджього) від повсякденного виразу 行ってきます (ittekimasu — «я пішов / до зустрічі»).
  Вживається при виході з дому перед старшими або при виході з офісу на ділову зустріч:
- Відповіддю є: 行ってらっしゃい (itterasshai) або ввічливіше 行ってらっしゃいませ (itterasshaimase).
- LEVEL :: beginner
- REGISTER :: polite
