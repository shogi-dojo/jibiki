- UK :: Прикметник та віддієслівний суфікс (-masu основа + やすい):
1. Самостійний прикметник: 易い (простий, легкий). У сучасній мові частіше вживається 易しい (やさしい / yasashii) або 簡単 (かんたん / kantan).
2. Суфікс схильності (значення 2): 壊れやすい (легко ламається / крихкий), 忘れやすい (забудькуватий).
3. Суфікс легкості виконання дії (значення 3): 読みやすい (легко читати), わかりやすい (зрозумілий).
- Антонім — 難い / にくい (nikui — важкий для виконання).
- Не плутати з омофоном 安い (дешевий).
- LEVEL :: beginner
- REGISTER :: neutral
