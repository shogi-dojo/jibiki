# Additional N2 candidate evidence

[Nihon Torii N2 vocabulary](https://www.nihontorii.com/jlpt/n2/vocabulary)
provides 11 selected candidates for the 1700-word branch continuation.
Retrieved 2026-10-04; page reports 1784 study-list words, updated 2026-09-23.
This is a candidate classification, not an official JLPT syllabus.

Candidate numbers are one-based positions of vocabulary cards in the source HTML.
All forms and readings were reconciled against pinned JMdict and existing IDs;
ambiguous matches, malformed readings, and duplicate IDs were excluded.
`selected.tsv` records source positions, lexical metadata, and entry paths.
Source definitions and examples are not copied; Ukrainian glosses, notes, and
Japanese examples are independently authored. The HTML is not redistributed.
