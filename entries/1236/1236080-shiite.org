- UK :: 強いて описує дію попри опір, незручність або відсутність очевидного вибору: 強いて求める. Усталене 強いて言えば — «якщо вже треба сказати», коли мовець змушує себе обрати відповідь. Не обов'язково фізична сила; тиск може бути умовою розмови або власною вимогою.
- LEVEL :: intermediate
- REGISTER :: neutral
