- UK :: =人を呼び止める= — окликнути людину, щоб вона зупинилася; також покликати таксі. Об'єкт через =を=. =呼ぶ= лише кликати, =止める= зупиняти будь-яким способом; складне дієслово поєднує обидві дії.
- LEVEL :: intermediate
- REGISTER :: neutral
