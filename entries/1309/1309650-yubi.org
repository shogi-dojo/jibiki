- UK :: Іменник 指 (ゆび / yubi) позначає палець на руці (手の指) або на нозі (足の指). Назви пальців руки: 親指 (oyayubi — великий), 人差し指 (hitosashiyubi — вказівний), 中指 (nakayubi — середній), 薬指 (kusuriyubi — безіменний), 小指 (koyubi — мізинець). Похідне слово: 指輪 (yubiwa — каблучка, перстень).
- LEVEL :: beginner
- REGISTER :: neutral
