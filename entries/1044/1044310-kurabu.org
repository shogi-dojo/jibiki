- UK :: Запозичення з англійської (club):
  1. Розважальний заклад / нічний клуб або хостес-клуб: 高級クラブ (елітний нічний клуб).
  2. Спортивна секція чи шкільний гурток (значення 2): クラブ活動 (club katsudou — діяльність шкільних гуртків / секцій), サッカークラブ (футбольний клуб).
  3. Ключка для гольфу (значення 3: ゴルフクラブ).
  4. Картярська масть трефа / хрести (значення 4).
- Історичний запис канджі — 倶楽部 (атеджі).
- LEVEL :: beginner
- REGISTER :: neutral
