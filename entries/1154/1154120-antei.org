- UK :: Іменник та дієслово suru (安定する — бути стабільним / стабілізуватися):
- Вживається у різноманітних сферах:
  - Медицина: 容態が安定する (стан хворого стабілізувався).
  - Економіка / кар'єра: 安定した収入 / 職業 (стабільний дохід / постійна робота), 物価の安定 (стабільність цін).
  - Психологія: 心の安定 (душевна рівновага).
- Антонім: 不安定 (ふあんてい / fuantei — нестабільний, хиткий).
- LEVEL :: beginner
- REGISTER :: neutral
