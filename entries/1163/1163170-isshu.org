** Learner notes
*** note-s-1163170-001-001
:PROPERTIES:
:END:
- UK :: Іменник «вид / сорт / різновид»:
- Вживання:
  - Один вид із багатьох: この一種だけが売れている (このいっしゅだけがうれている / kono isshu dake ga urete iru — продається лише цей один вид).
  - Найчастіше у сполуці 一種の… (いっしゅの / isshu no — «своєрідний, свого роду»): 一種の趣味 (いっしゅのしゅみ / isshu no shumi — своєрідне хобі).
- Наближені слова:
  - 種類 (しゅるい / shurui — вид, тип; нейтральний класифікаційний термін).
  - ある種の (あるしゅの / arushu no — певного роду, деякий).
- LEVEL :: beginner
- REGISTER :: neutral
