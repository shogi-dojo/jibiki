- UK :: Оптичний прилад для спостереження за далекими об'єктами (телескоп, підзорна труба). Для спостереження обома очима зазвичай слугує 双眼鏡[そうがんきょう] (бінокль), а для дрібних об'єктів — 顕微鏡[けんびきょう] (мікроскоп). До спеціальних типів належать 宇宙望遠鏡[うちゅうぼうえんきょう] (космічний телескоп) та 電波望遠鏡[でんぱぼうえんきょう] (радіотелескоп).
