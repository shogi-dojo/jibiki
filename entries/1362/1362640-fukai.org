** Learner notes
Прикметник "深い" (fukai) у своєму основному значенні описує велику глибину води, снігу, ями тощо.
** Examples
*** Beginner
- JA :: ここの海はとても深いです。
- READING :: ここ の うみ は とても ふかい です。
- UK :: Море тут дуже глибоке.
- EN :: The sea here is very deep.
- FOCUS :: 深い
*** Neutral
- JA :: この川は深いので、泳ぐのは危険です。
- READING :: この かわ は ふかい ので、 およぐ の は きけん です。
- UK :: Ця річка глибока, тому плавати тут небезпечно.
- EN :: This river is deep, so it's dangerous to swim.
- FOCUS :: 深い
*** Intermediate
- JA :: 彼女の言葉には深い意味が込められています。
- READING :: かのじょ の ことば に は ふかい いみ が こめられて います。
- UK :: У її словах закладено глибокий сенс.
- EN :: There is a profound meaning hidden in her words.
- FOCUS :: 深い
