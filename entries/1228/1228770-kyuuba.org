- UK :: Складений іменник із 急 («нагальний, раптовий») та 場 («місце, ситуація»). Позначає гостру, непередбачену кризу, що вимагає негайної реакції. Типові стійкі вислови: 急場をしのぐ («пережити скрутний момент; тимчасово вийти із скрути»), 急場を救う («виручити в критичну мить»), 急場しのぎ («тимчасова латка, нашвидкуруч вжитий захід»).
- LEVEL :: advanced
- REGISTER :: neutral
