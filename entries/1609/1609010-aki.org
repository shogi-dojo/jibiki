** Learner notes
*** note-s-1609010-001-001
:PROPERTIES:
:END:
- UK :: Іменник від дієслова 空く (aku — бути вільним / порожнім):
1. Вільне місце, простір (空きスペース — вільний простір, 空き地 — пустир).
2. Вільне місце / номер, вакансія (значення 2: 空き部屋 — вільна кімната, 空き席 — вільне місце).
3. Вільний час / вікно в розкладі (значення 3: 空き時間 — вільний час).
4. Порожня тара / незаселене житло (значення 4: 空き缶 — порожня бляшанка, 空き家 — порожній дім).
- LEVEL :: beginner
- REGISTER :: neutral
