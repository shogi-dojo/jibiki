** Learner notes
*** note-s-2019640-001-001
:PROPERTIES:
:END:
- UK :: Іменник та лічильний суфікс 杯 (он'йом はい / hai, зі змінами вимови ぱい / pai, ばい / bai):
1. Чарка / чаша алкоголю: 祝杯 (shukuhai — святковий келих), 乾杯 (kanpai — «будьмо!», тост).
2. Лічильний суфікс для наповнених чашок, склянок, мисок чи ложок (значення 2: 一杯 — одна чашка/склянка, 二杯 — дві, 三杯 — три).
3. Лічильний суфікс для невеликих суден (значення 3) та восьминогів чи кальмарів (значення 4).
4. Спортивний кубок чи кубковий турнір (значення 5: 優勝杯 — кубок переможця).
- Окремий предмет «чарка для саке» часто читається さかずき (sakazuki).
- LEVEL :: beginner
- REGISTER :: neutral
