** Learner notes
*** note-s-2008740-001-001
:PROPERTIES:
:END:
- UK :: Прислівник そんなに (sonnani) вказує на високу міру або ступінь («настільки», «так сильно»). У заперечних реченнях часто вживається у значенні «не настільки», «не так уже й»: そんなに高くない (не такий уже й дорогий), そんなに難しくない (не настільки складно).
- LEVEL :: beginner
- REGISTER :: neutral
** Examples
*** ex-2008740-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: 今日はそんなに寒くないですから、上着はいりません。
- READING :: きょうはそんなにさむくないですから、うわぎはいりません。
- ROMAJI :: Kyou wa sonnani samukunai desu kara, uwagi wa irimasen.
- UK :: Сьогодні не настільки холодно, тому куртка не потрібна.
- EN :: It is not that cold today, so a jacket is not needed.
- FOCUS :: そんなに寒くない
*** ex-2008740-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: まだ時間がありますから、そんなに急がなくてもいいですよ。
- READING :: まだじかんがありますから、そんなにいそがなくてもいいですよ。
- ROMAJI :: Mada jikan ga arimasu kara, sonnani isoganakutemo ii desu yo.
- UK :: Час ще є, тому не варто так поспішати.
- EN :: There is still time, so you don't need to hurry so much.
- FOCUS :: そんなに急がなく
*** ex-2008740-001-003
:PROPERTIES:
:LEVEL: intermediate
:REGISTER: neutral
:END:
- JA :: 初めての経験なのですから、失敗することをそんなに恐れる必要はありません。
- READING :: はじめてのけいけんなのですから、しっぱいすることをそんなにおそれるひつようはありません。
- ROMAJI :: Hajimete no keiken na no desu kara, shippai suru koto o sonnani osoreru hitsuyou wa arimasen.
- UK :: Оскільки це ваш перший досвід, не потрібно так сильно боятися припуститися помилки.
- EN :: Since this is your first time, there is no need to fear making mistakes so much.
- FOCUS :: そんなに恐れる
