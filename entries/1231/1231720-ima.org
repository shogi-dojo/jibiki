** Learner notes
*** note-s-1231720-001-001
:PROPERTIES:
:END:
- UK :: Іменник «вітальня»:
- Типові контексти:
  - 居間でテレビを見る (いまでてれびをみる / ima de terebi o miru — дивитися телевізор у вітальні).
  - 家族が居間に集まる (かぞくがいまにあつまる / kazoku ga ima ni atsumaru — родина збирається у вітальні).
- Відмінність від близьких слів:
  - 居間 (いま / ima) — загальна кімната для щоденного життя родини, часто із диваном і телевізором.
  - リビング (りびんぐ / ribingu — «лівінґ») — те саме, але запозичене слово, частіше в сучасній розмовній мові та рекламі нерухомості.
  - 客間 (きゃくま / kyakuma) — кімната для прийому гостей.
  - 茶の間 (ちゃのま / chanoma) — традиційна загальна кімната з татамі; побутовіше, з домашнім відтінком.
- Ремарка:
  - Не плутати з омонімом 今 (いま / ima — «зараз»); контекст завжди відрізняє ці слова.
- LEVEL :: beginner
- REGISTER :: neutral
