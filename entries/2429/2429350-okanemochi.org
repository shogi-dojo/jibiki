- UK :: Ввічливіший варіант слова 金持ち (kanemochi) з гонорифічним префіксом お- (o-):
- お金持ちになる (стати заможним / розбагатіти)
- 大金持ち (おおかねもち — багатій-магнат, мультимільйонер).
- LEVEL :: beginner
- REGISTER :: neutral
** Examples
*** ex-2429350-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: 彼はとてもお金持ちです。
- READING :: かれはとてもおかねもちです。
- ROMAJI :: Kare wa totemo okanemochi desu.
- UK :: Він дуже багата людина.
- EN :: He is a very wealthy person.
- FOCUS :: お金持ちです
*** ex-2429350-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: 将来成功してお金持ちになったら、世界中を旅しながら困っている人たちを支援する慈善活動を行いたいです。
- READING :: しょうらいせいこうしておかねもちになったら、せかいじゅうをたびしながらこまっているひとたちをしえんするじぜんかつどうをおこないたいです。
- ROMAJI :: Shourai seikou shite okanemochi ni nattara, sekaijuu o tabi shinagara komatte iru hitotachi o shien suru jizen katsudou o okonaitai desu.
- UK :: Якщо в майбутньому я досягну успіху й стану заможною людиною, то хочу подорожувати світом і займатися благодійністю, підтримуючи тих, хто у скруті.
- EN :: If I succeed and become rich in the future, I want to travel around the world while doing charity work to help people in need.
- FOCUS :: お金持ちになったら

- UK :: Справжня цінність полягає не в тому, щоб просто розбагатіти, а в тому, щоб через підприємництво вирішувати суспільні проблеми та робити життя людей якіснішим.
- EN :: Rather than merely aiming to become a wealthy person, true value lies in solving social issues through business and enriching many people's lives.
