- UK :: Випадковий збіг або непередбачувана подія (~単なる偶然~ — простий збіг обставин, ~偶然の一致~ — випадковий збіг). Протилежне поняття — ~必然~ (неминучість, закономірність).
- LEVEL :: intermediate
- REGISTER :: neutral
