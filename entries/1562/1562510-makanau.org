** Learner notes
*** note-s-1562510-001-001
:PROPERTIES:
:END:
- UK :: 賄う означає забезпечувати потреби певним ресурсом: 費用を賄う, 収入で生活を賄う. Частка で позначає джерело, а を — потребу або витрати. Часто пишеться каною まかなう; не тотожне простому 支払う, бо акцентує достатність джерела для забезпечення потреб.
- LEVEL :: intermediate
- REGISTER :: neutral
** Examples
*** ex-1562510-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: 会費で費用を賄う。
- READING :: かいひでひようをまかなう。
- UK :: Витрати покриваємо членськими внесками.
- EN :: We cover the costs with membership fees.
- FOCUS :: 賄う

- UK :: Потрібну електроенергію забезпечують сонячною енергією.
- EN :: The required electricity is supplied by solar power.
- FOCUS :: 賄っている

- UK :: Оскільки самих пожертв не вистачало на поточні витрати, ми розглянули інші джерела доходу.
- EN :: Because donations alone could not cover operating costs, we considered other income sources.
- FOCUS :: 賄えない
