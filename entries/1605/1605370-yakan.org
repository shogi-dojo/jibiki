- UK :: Зазвичай побутовий чайник для кип'ятіння води: やかんで湯を沸かす. Часто пишеться каною やかん; відрізняється від 急須, призначеного для заварювання чаю. Слово саме не визначає джерело нагрівання.
- LEVEL :: intermediate
- REGISTER :: neutral
