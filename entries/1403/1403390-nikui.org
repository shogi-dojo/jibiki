** Learner notes
*** note-s-1403390-001-001
:PROPERTIES:
:END:
- UK :: І-прикметник для вираження сильної відрази, злості чи обурення:
- 憎い相手 (ненависний противник / суперник)
- 憎む (にくむ — ненавидіти)
- 憎らしい (にくらしい — дратівливий, огидний).
  У розмовному стилі (значення 2) іноді виражає напівжартівливе схвалення чи заздрість («ай спритний!», «от уміє ж!»: 憎い演出 — майстерна витівка).
  Не плутати з суфіксом 〜難い / 〜にくい (складний для дії: 読みにくい — важкочитабельний).
- LEVEL :: beginner
- REGISTER :: neutral
