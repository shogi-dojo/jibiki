- UK :: Перехідне дієслово (五段 на -う), утворене з 見る (дивитися) та суфікса 損なう (зробити невдало, схибити). Позначає хибне судження про обставини, обсяг чи значення чогось, наприклад 事態を見損なう (неправильно оцінити ситуацію).
- LEVEL :: advanced
- REGISTER :: neutral
