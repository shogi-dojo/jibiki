- UK :: Розмовний, дещо грубуватий іменник для позначення блювання або блювотних мас (частіше записується каною へど/ヘド або канджі 反吐). Крім прямого значення вживається у різкому переносному звороті 反吐が出る («аж верне / нудить від огиди» до чиєїсь поведінки чи лицемірства); нейтральніший медичний відповідник — 嘔吐 (おうと).

- REGISTER :: neutral
