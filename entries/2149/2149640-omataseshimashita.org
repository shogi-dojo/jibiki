- UK :: Формульна фраза ввічливості (казуатив від 待つ — 待たせる + шаноблива рамка お〜する):
- Вживається офіціантами/продавцями при подачі замовлення або колегами при затримці.
- Неформальний розмовний варіант: お待たせ (omatase).
- Скромно-шанобливий офіційний варіант: 大変お待たせいたしました (taihen omatase itashimashita).
- LEVEL :: beginner
- REGISTER :: polite
