** Learner notes
Вживається для опису чогось, що є незручним у використанні, або ситуації, що завдає клопоту.
** Examples
*** Example 1
- JA :: ここは交通が不便だ。
- READING :: ここは こうつうが ふべんだ。
- UK :: Тут незручне транспортне сполучення.
- EN :: The transportation here is inconvenient.
- FOCUS :: 不便 (ふべん)
*** Example 2
- JA :: スマホがないと不便です。
- READING :: スマホが ないと ふべんです。
- UK :: Без смартфона незручно.
- EN :: It is inconvenient without a smartphone.
- FOCUS :: 不便 (ふべん)
*** Example 3
- JA :: 不便な場所にあるお店ですが、いつも混んでいます。
- READING :: ふべんな ばしょに ある おみせですが、 いつも こんでいます。
- UK :: Хоча магазин розташований у незручному місці, там завжди багато людей.
- EN :: Although the shop is in an inconvenient location, it's always crowded.
- FOCUS :: 不便な (ふべんな)
