- UK :: Базовий іменник на позначення фізичного краю або кінця:
  1. Край чи кінець простору/предмета: 道の端 (узбіччя дороги), 机の端 (край столу), 橋の端 (край моста).
  2. Початок або витік (значення 2): 端を発する (hashi o hassuru — брати початок).
  3. Дрібні залишки чи деталі (значення 3): 言葉の端々に (у кожному натяку/слові).
  Зверніть увагу на відому гру слів та омофони:
- 橋 (hashi — міст)
- 箸 (hashi — палички для їжі)
- 端 (hashi — край).
- LEVEL :: beginner
- REGISTER :: neutral
