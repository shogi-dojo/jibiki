- UK :: Дієслово «とおる» (тоору) означає «проходити», «проїжджати» або «минати» певне місце. Зазвичай вказує на рух через або вздовж якогось простору, наприклад, вулицею чи мостом. Зверніть увагу: місце, через яке відбувається рух, оформлюється часткою «を» (о) (наприклад, «道をとおる» — йти дорогою), оскільки це дієслово руху.
- LEVEL :: beginner
- REGISTER :: neutral
