- UK :: Іменник, що зазвичай пишеться каною (たたら або タタラ), хоча має традиційні записи 踏鞴, 蹈鞴 та 鑪. Позначає великі ножні міхи для нагнітання повітря в піч; звідси походить вислів たたらを踏む («оступатися, робити поспішні кроки, наче ступаючи на міхи»).
- LEVEL :: advanced
- REGISTER :: neutral
