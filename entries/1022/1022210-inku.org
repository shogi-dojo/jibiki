*** note-s-1022210-001-001
:PROPERTIES:
:END:
- UK :: Запозичення з англійської (ink):
- Позначає чорнило для авторучок, маркерів, принтерів:
  - インクが出る / 出ない (чорнило пише / не пише)
  - インクが切れる / なくなる (чорнило закінчилося)
  - インクカートリッジ (чорнильний картридж).
- Традиційну японську туш для каліграфії та сумі-е зазвичай називають 墨 (すみ / sumi).
- LEVEL :: beginner
- REGISTER :: neutral
