- UK :: Небесне світило: 月が出る (сходить місяць), 満月 (повний місяць / повня), 三日月 (серп місяця / молодик), お月見 (традиційне милування осіннім місяцем). Також означає календарний місяць (значення 2: 月に一度 — раз на місяць) або супутник планети (значення 4).
- LEVEL :: beginner
- REGISTER :: neutral
