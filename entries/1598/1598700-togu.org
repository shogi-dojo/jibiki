- UK :: 研ぐ — перехідне дієслово для загострення леза: 包丁を研ぐ, はさみを研ぐ. Той, хто діє, робить предмет гострішим; 自動詞の「切れる」 описує здатність різати. Для поліпшення майстерності переносно вживають 感覚を研ぎ澄ます, але просте 研ぐ насамперед пов'язане з фізичним точінням.
- LEVEL :: intermediate
- REGISTER :: neutral
