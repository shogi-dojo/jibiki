** Learner notes
*** note-s-1605250-001-001
:PROPERTIES:
:END:
- UK :: Зазвичай =もったいない=. Оцінює втрату цінності: =食べ物を捨てるのはもったいない=, =時間がもったいない=. Не просто «дорого» (=高い=), а «шкода витрачати чи викидати». Може бути окремим вигуком «Яка шкода!».
- LEVEL :: intermediate
- REGISTER :: neutral
** Examples
*** ex-1605250-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: まだ使えるのに、捨てるのはもったいない。
- READING :: まだつかえるのに、すてるのはもったいない。
- UK :: Воно ще придатне, тож шкода викидати.
- EN :: It still works, so throwing it away would be a waste.
- FOCUS :: もったいない
*** ex-1605250-001-002
:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral
:END:
- JA :: 料理を残すともったいないので、少しずつ注文した。
- READING :: りょうりをのこすともったいないので、すこしずつちゅうもんした。
- UK :: Щоб не марнувати їжу, ми замовляли невеликими порціями.
- EN :: We ordered small portions to avoid wasting food.
- FOCUS :: もったいない
*** ex-1605250-001-003
:PROPERTIES:
:LEVEL: intermediate
:REGISTER: neutral
:END:
- JA :: せっかく身につけた技術を使わずに終わるのはもったいないと思う。
- READING :: せっかくみにつけたぎじゅつをつかわずにおわるのはもったいないとおもう。
- UK :: Гадаю, шкода так і не скористатися навичками, яких здобули з такими зусиллями.
- EN :: I think it would be a shame never to use skills acquired with so much effort.
- FOCUS :: もったいない
