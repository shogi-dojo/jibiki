- UK :: Іменник, утворений із 札 (паперова купюра, банкнота) та 入れる (класти всередину). Позначає плоский гаманець для паперових грошей і карток, зазвичай без відділення для дріб'язку — на відміну від 小銭入れ (монетниці) чи загального 財布.
- LEVEL :: advanced
- REGISTER :: neutral
