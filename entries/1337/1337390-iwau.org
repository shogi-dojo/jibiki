** Learner notes
*** note-s-1337390-001-001
:PROPERTIES:
:END:
- UK :: Дієслово 5-ї групи (v5u, transitive) «святкувати / вітати»:
- Граматика:
  - 祝う → 祝わない / 祝います / 祝って / 祝った (iwawanai / iwaimasu / iwatte / iwatta).
  - Типова конструкція: «подію + を祝う»: 誕生日を祝う (たんじょうびをいわう / tanjoubi o iwau — святкувати день народження).
- Типові сполучення:
  - 合格を祝う (ごうかくをいわう / goukaku o iwau — вітати зі складеним іспитом).
  - 新年を祝う (しんねんをいわう / shinnen o iwau — відзначати Новий рік).
- Відмінність від близьких слів:
  - 祝う (いわう / iwau) — дієслово; іменник від нього — 祝い (いわい / iwai).
  - おめでとう (おめでとう / omedetou) — вигук «вітаю!».
  - 祝福する (しゅくふくする / shukufuku suru — благословляти) — урочистіше, релігійне забарвлення.
- LEVEL :: beginner
- REGISTER :: neutral
