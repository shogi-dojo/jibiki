- UK :: 他方 як іменник називає одну з двох сторін або інший напрям: 一方と他方. Не обов'язково протилежну політичну позицію; контекст визначає учасників або просторові сторони. Частки після слова показують його роль у реченні, на відміну від сполучного вживання.
- LEVEL :: intermediate
- REGISTER :: neutral
