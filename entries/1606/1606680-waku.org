** Learner notes
*** note-s-1606680-001-001
:PROPERTIES:
:END:
- UK :: Неперехідне дієслово I дієвідміни (godan) 沸く (わく / waku) означає закипання рідини чи нагрівання ванни: お湯が沸く (oyu ga waku — «вода кипить»), お風呂が沸く (ofuro ga waku — «ванна готова / нагрілася»). Перехідна пара — 沸かす (wakasu — «кип'ятити / гріти»). У переносному значенні вживається про бурхливі овації глядачів: 会場が沸く (kaijou ga waku — «зал вибухає оплесками»).
- LEVEL :: beginner
- REGISTER :: neutral
** Examples
*** ex-1606680-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:
- JA :: お湯が沸いたので、コーヒーを入れましょう。
- READING :: おゆがわいたので、こーひーをいれましょう。
- ROMAJI :: Oyu ga waita node, koohii o iremashou.
- UK :: Вода закипіла, тож заварімо кави.
- EN :: The water has boiled, so let's make coffee.
- FOCUS :: 沸いたので

:PROPERTIES:

:END:

- READING :: おふろがちょうどいいおんどにわいたので、さめないうちにすぐにはいりました。
- ROMAJI :: Ofuro ga choudo ii ondo ni waita node, samenai uchi ni sugu ni hairimashita.
- UK :: Ванна нагрілася до комфортної температури, тому я одразу пішов купатися, поки вода не охолола.
- EN :: The bath reached just the right temperature, so I got in immediately before it cooled down.
- FOCUS :: 沸いたので

- READING :: やかんのゆがいきおいよくわいてゆげがたちのぼるのをみながら、しずかなあさのじかんをすごしました。

- UK :: Споглядаючи, як у чайнику бурхливо кипить вода й клубочиться пара, я насолоджувався тихим ранком.

- FOCUS :: 沸いて
