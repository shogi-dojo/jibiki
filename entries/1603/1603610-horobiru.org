- UK :: 滅びる — неперехідне дієслово для знищення або остаточного занепаду держави, виду чи цивілізації: 国が滅びる. Перехідне 滅ぼす означає знищити. Має вагоме, часто історичне чи літературне звучання; просто 古くなる або 廃れる не обов'язково передбачає такий радикальний кінець.
- LEVEL :: intermediate
- REGISTER :: neutral
