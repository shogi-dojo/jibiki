*** note-s-1602440-001-001
:PROPERTIES:
:END:
- UK :: Неперехідне дієслово (автоматична дія). Означає збільшення кількості, обсягу або числа чогось. Протилежність — 減る (херу, зменшуватися). Для перехідного значення "збільшувати" використовується 増やす (фуясу).
- LEVEL :: beginner
- REGISTER :: neutral
