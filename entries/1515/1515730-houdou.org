- UK :: 報道する — повідомляти новини через медіа: 事件を報道する・報道によると. Це не кожне особисте повідомлення 連絡; слово називає публічне новинне висвітлення, а 取材 — діяльність зі збирання потрібних для нього матеріалів.
- LEVEL :: intermediate
- REGISTER :: neutral
