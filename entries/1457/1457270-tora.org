- UK :: Іменник, що позначає третій знак дванадцятирічного циклу земних гілок (十二支). На відміну від звичайного слова 虎 (тварина тигр), ієрогліф 寅 уживається саме для календарних, астрологічних та традиційних позначень, наприклад у слові 寅年 (рік Тигра).
- LEVEL :: advanced
- REGISTER :: neutral
