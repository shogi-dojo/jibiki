- UK :: Дієслово 1-ї групи (ґодан) на позначення ткацтва:
- 布を織る (ткати тканину / полотно)
- 機織り (はたおり — ткацтво, робота за верстатом)
- 織物 (おりもの — текстиль, ткана матерія).
Не плутати з омонімами 折る (oru — згинати, ламати) та 居る / おる (oru — скромна форма дієслова «бути / знаходитися»).
- LEVEL :: beginner
- REGISTER :: neutral
