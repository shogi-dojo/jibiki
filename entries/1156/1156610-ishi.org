** Learner notes
*** note-s-1156610-001-001
:PROPERTIES:
:END:
- UK :: Іменник «намір / волевиявлення / думка»:
- Позначає свідому позицію, намір або згоду (ієрогліф 思 — думка):
  - 意思表示 (висловлення наміру / волевиявлення)
  - 意思疎通 (взаєморозуміння, комунікація між сторонами)
  - 意思を確認する (з'ясувати намір / згоду).
- Відмінність від 意志 (ishi): 意思 вживається для юридичного або повсякденного волевиявлення/думки, а 意志 — для сили волі й цілеспрямованості.
- LEVEL :: beginner
- REGISTER :: neutral
