- UK :: Робити або говорити щось знову і знову, повторювати дію (~何度も繰り返す~ — повторювати багато разів, ~同じ失敗を繰り返す~ — повторювати ту саму помилку).
- LEVEL :: beginner
- REGISTER :: neutral
** Examples
*** ex-1247030-001-001
:PROPERTIES:
:LEVEL: beginner
:REGISTER: neutral
:END:

- READING :: なんどもれんしゅうをくりかえしました。
- UK :: Я тренувався знову і знову.
- EN :: I repeated the practice many times.
- FOCUS :: 繰り返しました

:PROPERTIES:
:LEVEL: neutral
:REGISTER: neutral

- READING :: おなじしっぱいをくりかえさないようにきをつけます。
- UK :: Я буду обачним, щоб не повторювати ту саму помилку.
- EN :: I will be careful not to repeat the same mistake.
- FOCUS :: 繰り返さない
