- UK :: Загальний науковий і побутовий термін для позначення температури (води, повітря, речовини, тіла): =温度を測る= (вимірювати температуру), =温度が上がる／下がる= (температура піднімається/опускається), =温度計= (=おんどけい=, термометр). Для температури повітря (погоди) частіше вживається =気温= (=きおん=), а для температури тіла — =体温= (=たいおん=).

- REGISTER :: neutral
